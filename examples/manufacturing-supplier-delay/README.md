# 案例二｜製造業供應商延遲

> 本目錄為方法論教學用的合成案例；供應商、數據、分數與審核結果均為示範資料，不代表真實企業成效。

## 任務

當供應商延遲超過 10 天且原料價格上升超過 10%，協助營運團隊評估庫存、替代供應商、議價與交期風險，產出可供主管決策的處置方案。

這是一個 **R3 高影響決策案例**。AI Golfer 可以分析與準備方案，但不得自行更換供應商、簽約、下單或對外承諾。

## 教學重點

- 同樣是資料分析，因不可回復性與商業影響提高，決策權必須升級。
- 高階模型並不代表可以跳過證據、採購規範與主管核准。
- VAC 保存的是「如何準備合格決策材料」，不是取代採購負責人。
