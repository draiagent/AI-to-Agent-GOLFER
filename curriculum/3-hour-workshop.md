# 3 小時企業工作坊

## 目標

讓一個部門在三小時內，從真實任務完成可評審的 Enterprise Shot Card。

| 時間 | 活動 | 產出 |
| --- | --- | --- |
| 00:00–00:20 | AI Coach、AI Golfer 與模型球桿 | 任務選題 |
| 00:20–00:50 | GOLFER 閉環與風險分級 | 初版閉環 |
| 00:50–01:30 | VAD + Memory | Course Map／Memory Pack |
| 01:30–02:00 | Decision + Routing | Decision Record |
| 02:00–02:35 | Workflow + Verify | 執行流程與 Scorecard |
| 02:35–02:50 | VAC + Brand | 能力草案與品牌護欄 |
| 02:50–03:00 | Pitch + Commitment | 7 天行動 |

## 選題限制

- 高頻、可量測、可取得資料。
- 低至中風險，或能在沙盒中測試。
- 不選需要即時金流、重大人事、醫療判斷或不可回復外部行動的任務。

## 最終交付

每組以三分鐘回答：目標、球位、風險、決策、選桿、Workflow、Verify，以及為何現在還不能或可以轉成 VAC。
