# 04｜企業成熟度與導入路線

## 五階段成熟度

| 階段 | 高爾夫比喻 | 企業行為 | 升級證據 |
| --- | --- | --- | --- |
| L1 Chat | 練習場試打 | 個人問答、無標準 | 能說明高價值任務與風險 |
| L2 Work | 固定揮桿練習 | 有 Prompt、模板、人工搬運 | 任務有 VAD 與 Verify |
| L3 Workflow | 下場前例行程序 | 步驟與工具串接、可追蹤 | 成功率、成本與錯誤可量測 |
| L4 Agent | 球員自主完成一球 | 會判斷、執行、修復、升級 | 有決策權、停止條件與稽核 |
| L5 Learning Enterprise | 球隊與賽季管理 | VAC、Memory、品牌與治理複利 | 重用率提升且風險受控 |

## 90 天導入路線

### 0–30 天：選洞，不選工具

- 盤點 10–20 個高頻任務。
- 以價值、風險、重複性、資料可得性排序。
- 選 1 個低至中風險流程做 VAD。
- 定義 Baseline：時間、成本、錯誤、返工、品牌一致性。

### 31–60 天：打出可驗證的一球

- 建立 Memory Pack、Decision Rule 與 Workflow。
- 設定模型與工具路由，但保留人工核准。
- 跑 10–30 次真實或沙盒任務。
- 記錄失敗模式、成本、人工介入與 Verify。

### 61–90 天：形成第一個 VAC

- 只把穩定且通過驗收的流程固化。
- 建立版本、Owner、權限、失效日期與回復機制。
- 訓練第二位使用者或部門重用。
- 決定下一個相鄰任務，不同時擴張所有部門。

## 導入優先矩陣

| 任務特徵 | 建議 |
| --- | --- |
| 高頻、規則清楚、低風險 | 第一批自動化 |
| 高頻、規則清楚、高風險 | 先做輔助與 Verify，不直接自動執行 |
| 低頻、高價值、未知 | 高階模型探索，保留人類決策 |
| 低頻、低價值、資料混亂 | 暫緩，先改善資料與流程 |
