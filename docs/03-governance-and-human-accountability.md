# 03｜治理與人類決策權

## 決策風險矩陣

| 風險級別 | 典型任務 | AI 權限 | 人類責任 |
| --- | --- | --- | --- |
| R0 | 內部格式整理、分類 | 可自動執行 | 抽查與設定規則 |
| R1 | 草稿、摘要、低影響建議 | 可執行並標示 AI | 定期審查 |
| R2 | 對外內容、營運建議 | 執行後須核准 | 核准內容與品牌 |
| R3 | 財務、人事、法律、健康、安全 | 僅分析或準備材料 | 合格專家最終決定 |
| R4 | 不可回復、重大損害或超越授權 | 必須停止與升級 | 組織正式決策程序 |

## 四道護欄

1. **Data Gate**：資料能否進入模型？是否含機密、個資或受限制內容？
2. **Decision Gate**：Agent 是否有權做這項決定？
3. **Action Gate**：能否直接寫入、發布、付款、寄送或改變外部狀態？
4. **Reuse Gate**：這次成果是否足以成為 VAC？

## 必須停止的情境

- 關鍵資料矛盾、缺漏或無法追溯。
- 需要新權限、憑證或未授權外部行動。
- 任務涉及重大法律、醫療、財務、安全或人事後果，卻缺少合格核准者。
- Workflow 進入重複失敗或成本超限。
- 品牌承諾、數據或聲明無法被驗證。

## 決策可追溯性

每個 Decision Record 至少保存：

- 當時目標與輸入版本。
- 使用的 Memory 與來源。
- 考慮過的策略與選擇理由。
- 風險級別與授權者。
- 模型、工具、Workflow 與成本。
- Verify 結果、人工修改與最終決定。

治理的目的不是讓 Agent 什麼都不能做，而是讓它知道「可以自主到哪裡」。
